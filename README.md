# Wallstreet

A virtual stock-market simulation: trade, invest and build a portfolio. A **[Credenz](https://github.com/PICT-IEEE-Student-Branch)** event by the PICT IEEE Student Branch.

| Year | Material |
|---|---|
| **2026** | 🔜 [`2026/`](2026/) |

**Where do I push?** Put each year's platform code, questions or problem statements, rulebook and notes for next year in that year's folder: `2026/`, `2027/`, …
Answers go in only after the event is over. Never commit `.env` files, API keys or participants' data.
